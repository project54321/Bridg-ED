# 🧠 BridgEd

**BridgEd** is a clean, ad-free flashcard web app built with **Vanilla JavaScript, HTML, and CSS**.  
It’s designed to help students study efficiently — without distractions, clutter, or unnecessary features.

👉 **Live Demo:** [bridg-ed.vercel.app](https://bridg-ed.vercel.app/)

---

## ✨ Features

- 📚 **Simple Flashcards:** Quickly review concepts, definitions, or terms with a clean interface.  
- 🚫 **No Ads, No Distractions:** 100% focus on studying — no popups, recommendations, or side content.  
- 🔁 **Interactive Flips:** Tap or click to flip cards and test your memory.  
- 💾 **Local Progress (Planned):** Save decks and review stats locally in future updates.  

---

## 🖥️ Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript  
- **Hosting:** Vercel  

No frameworks, no dependencies — just fast, lightweight code.

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/project54321/Bridg-ED.git
cd bridged
```

2. Run the app
Simply open the index.html file in your browser.

That’s it — no build tools or installations required.
